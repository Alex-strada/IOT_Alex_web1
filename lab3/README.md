# Lab 3 - Smart Parking

Simple HTML, CSS, and JavaScript in one file: `index.html`.

- 20 spaces start with random statuses.
- Green means available; red means occupied.
- Click a space to change its status.
- The dashboard shows total, occupied, available, and occupancy percentage.
- A simulated sensor changes one random space every 5 seconds.
- The provided parking image is shown as a reference.

All data is simulated. The 20 spaces are an example, not the real parking capacity.

Open `index.html` in a browser or visit:
